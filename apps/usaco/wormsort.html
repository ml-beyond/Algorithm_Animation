Wormsort: Why Connectivity Is Enough

This animation starts with a path of 5 locations. You can add more locations to see the same proof on a longer path. We swap along the path forward, then backward, so the endpoint cows exchange places and all middle cows return.

Key idea: In an undirected connected component, edge swaps can create any permutation of cows inside that component. This path animation proves the basic operation: we can swap any two endpoint cows on a path. Therefore, Wormsort only needs to check whether p[i] and i are in the same component.
